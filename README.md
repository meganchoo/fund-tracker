# Fund Tracker

A simple fund portfolio tracker with real-time data from TianTian Fund.

## Features

- Real-time fund data updates
- Auto-refresh every minute
- Local storage - data persists in browser
- Responsive design - works on mobile and desktop
- Add/remove funds easily

## Live Demo

Visit: https://meganchoo.github.io/fund-tracker/

## How to Use

1. Open the website
2. Click "Add Fund" button
3. Enter fund code, shares, and cost price
4. View real-time returns
